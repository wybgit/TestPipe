# Backlog

这个目录用于集中保存**当前尚未实现、但已经明确需要跟踪**的需求。

用途:

- 统一记录未实现需求
- 标记优先级、状态、落地范围
- 方便后续结合真实案例逐项推进

维护规则:

- 新增未实现需求时，先更新总表
- 复杂需求单独拆成独立文档
- 当需求落地后，从本目录移出或标记为已完成
