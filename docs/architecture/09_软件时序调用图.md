# 软件时序调用图

下面的时序图描述了当前主线 testcase 从 CLI 到 run 目录输出的调用顺序。

![TestPipe Software Sequence](../assets/software_sequence.svg)

## 1. 主流程说明

1. 用户通过 `testpipe run case.yaml` 触发执行。
2. CLI 调用 `TestCaseLoader` 解析 YAML，产出 `CaseSpec`。
3. CLI 根据 `case.pipeline` 创建 Pipeline 实例。
4. `PipelineCompiler` 生成 `PipelineSpec`。
5. `TestEngine` 按拓扑顺序执行节点：
   - `EnvCheckOp`
   - `ResourceFetchOp`
   - `ATCCompileOp`
   - `PathExistsOp`
6. `GraphExporter` 结合 `PipelineSpec + CaseSpec + outputs` 写出 DOT/PDF。
7. 执行器落盘 `summary.json`、step 日志和 artifacts。

## 2. 为什么导图在执行后更有价值

当前不是只导静态图，而是把运行时信息填进去：

- 输入参数
- 节点输出
- Pipeline 最终输出

因此导出的图既能看结构，也能看这次 case 实际用了什么参数、产生了什么结果。
