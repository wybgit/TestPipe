# 框架架构图

下面这张图对应当前 TestPipe 的实际实现分层。

![TestPipe Framework Architecture](../assets/framework_architecture.svg)

## 1. 分层说明

- 用例与文档层：YAML testcase、Docsify 文档、API 文档。
- 编排层：`Pipeline` DSL、节点句柄、输出引用。
- 编译层：`PipelineCompiler` 把作者视角的 DSL 编译成 `PipelineSpec`。
- 执行层：`TestEngine`、`StepContext`、artifact 管理、step 日志。
- 能力层：`EnvCheck / ResourceFetch / ATCCompile / PathExists` 等内置算子。
- 输出层：`runs/`、`summary.json`、`pipeline_graph.dot`、`pipeline_graph.pdf`。

## 2. 当前主线

当前仓库仅保留一个内置 Pipeline：

- `OnnxGitAtcPipeline`

其运行路径与这张图一致，核心对象关系是：

1. testcase YAML 进入 `TestCaseLoader`
2. Python Pipeline 进入 `PipelineCompiler`
3. 两者在 `TestEngine` 汇合
4. 执行结果再进入结果目录和导图模块
