# TestPipe测试框架 - 总体设计

## 1. 框架定位

TestPipe是一个**测试算子注册和调度平台**,用于NPU模型转换和推理的端到端测试。

### 核心理念
- **算子化测试** - 将测试步骤抽象为可复用的测试算子
- **管道化编排** - 使用有向图描述测试流程(Pipeline)
- **代码即配置** - Pipeline用Python代码定义,TestCase用YAML描述数据
- **统一API** - 测试算子调用统一封装的操作API

### 类比关系
```
AI编译器              TestPipe测试框架
─────────────────────────────────────
算子(Operator)    →  测试算子(TestOp)
计算图(Graph)     →  测试管道(Pipeline)
推理引擎(Runtime) →  测试引擎(TestEngine)
输入张量(Tensor)  →  测试用例(TestCase)
```

## 3. 核心概念

### Pipeline (测试流程)
- **定义**: 描述测试步骤的执行顺序和数据流
- **格式**: Python代码(类似PyTorch的nn.Module)
- **特点**: 可复用,灵活组合,IDE支持,可导出为ONNX/DOT可视化

### TestCase (测试用例)
- **定义**: 具体的测试实例,包含输入数据和期望结果
- **格式**: YAML
- **特点**: 易读易写,支持注释,引用Pipeline

### TestSuite (测试套件)
- **定义**: 批量测试用例的集合
- **格式**: YAML
- **特点**: 支持并行执行,生成报告

## 5. 测试场景覆盖

TestPipe框架设计支持以下5类测试场景:

1. **ATC模型转换测试** - 模型准备 → ATC编译 → 推理验证
2. **AscendC算子测试** - 算子编译 → 板端执行 → 精度比对
3. **自定义算子测试** - 算子注册 → 编译 → 集成测试
4. **AMCT量化测试** - 量化 → 编译 → 精度评估
5. **API接口测试** - 接口调用 → 结果验证

## 6. 关键设计原则

### 6.1 测试算子统一模板

所有测试算子必须遵循统一模板:

```python
class TestOp(ABC):
    """测试算子基类"""
    
    # 算子元信息
    op_type: str          # 算子类型
    op_category: str      # 算子分类
    
    # 输入输出
    inputs: List[str]     # 输入名称列表
    outputs: List[str]    # 输出名称列表
    
    # 配置参数
    attributes: Dict      # 算子属性
    
    # 核心方法
    def execute(self, context) -> Dict  # 执行逻辑
    def validate(self) -> bool          # 参数验证
```

### 6.2 统一操作API

测试算子通过统一API访问底层能力:

```python
# SSH操作API
api.ssh.connect(host, port, user)
api.ssh.execute(command)
api.ssh.disconnect()

# 文件传输API
api.transfer.upload(local_path, remote_path)
api.transfer.download(remote_path, local_path)

# 命令执行API
api.exec.run(command, timeout)
api.exec.run_async(command)
```

### 6.3 Pipeline和TestCase分离

**Pipeline (JSON)** - 定义流程:
```json
{
  "Pipeline_Name": "ATC_E2E_Pipeline",
  "Pipeline_Inputs": ["model_source", "soc_version"],
  "Pipeline_Outputs": ["test_passed"],
  "Steps": [
    {
      "Step_Name": "compile_model",
      "Step_Type": "ATCCompile",
      "Inputs": ["model_path", "soc_version"],
      "Outputs": ["om_path"],
      "Config": {
        "timeout": 600,
        "framework": 5
      }
    }
  ]
}
```

**TestCase (YAML)** - 定义数据:
```yaml
pipeline:
  name: OnnxGitAtcPipeline
  fetchModelNode:
    repo: https://github.com/wybgit/onnx-layer.git
    path: Abs_testcase_5a6b43
    model_pattern: "*.onnx"
  compileModelNode:
    soc_version: Ascend310P3
    env_script: /home/wyb/Ascend/cann-8.5.0/set_env.sh
  assertOmExistsNode:
    expected_value: true
cases:
  - case_id: onnx_git_atc_case
    description: 验证 Git 模型资源获取与 ATC 转换
    level: P0
```
