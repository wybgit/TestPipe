# 核心对象模型

## 1. 最重要的对象

- `Pipeline`
- `TestOp`
- `PipelineSpec`
- `CaseSpec`
- `StepContext`
- `TestEngine`

## 2. 关系

### Pipeline -> PipelineSpec

`Pipeline` 负责写图，`PipelineCompiler` 负责编译成 `PipelineSpec`。

### CaseSpec + PipelineSpec -> TestEngine

执行时：

- `PipelineSpec` 决定结构
- `CaseSpec` 提供参数

### TestEngine -> runs/

执行后输出：

- `summary.json`
- step 日志
- 工件
- 导图

## 3. 参数落点

- Pipeline 输入进 `CaseSpec.inputs`
- 节点参数进 `CaseSpec.inputs_by_node`
- 执行前按 `OpSpec` 自动拆成 `StepContext.inputs` 和 `StepContext.attrs`

## 4. 当前中心

当前对象模型的中心仍然是 `PipelineSpec`。
