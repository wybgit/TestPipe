## 2. 文档生成方案

### 2.1 使用Sphinx + autodoc

```bash
# 安装依赖
pip install sphinx sphinx-rtd-theme sphinx-autodoc-typehints

# 初始化Sphinx
cd docs
sphinx-quickstart
```

### 2.2 配置conf.py

```python
# docs/conf.py
import os
import sys
sys.path.insert(0, os.path.abspath('..'))

project = 'TestPipe'
copyright = '2026, TestPipe Team'
author = 'TestPipe Team'

extensions = [
    'sphinx.ext.autodoc',
    'sphinx.ext.napoleon',
    'sphinx.ext.viewcode',
    'sphinx_autodoc_typehints',
]

templates_path = ['_templates']
exclude_patterns = ['_build', 'Thumbs.db', '.DS_Store']

html_theme = 'sphinx_rtd_theme'
html_static_path = ['_static']

# autodoc配置
autodoc_default_options = {
    'members': True,
    'member-order': 'bysource',
    'special-members': '__init__',
    'undoc-members': True,
    'exclude-members': '__weakref__'
}
```

### 4.2 算子文档自动生成

```python
# scripts/generate_op_docs.py
from testpipe.core import OpRegistry

def generate_op_docs():
    """自动生成算子文档"""
    
    ops = OpRegistry.list_ops()
    
    with open('docs/source/api/ops.rst', 'w') as f:
        f.write("测试算子\n")
        f.write("========\n\n")
        
        for op_type in ops:
            op_class = OpRegistry.get(op_type)
            f.write(f"{op_type}\n")
            f.write("-" * len(op_type) + "\n\n")
            f.write(f".. autoclass:: {op_class.__module__}.{op_class.__name__}\n")
            f.write("   :members:\n")
            f.write("   :undoc-members:\n")
            f.write("   :show-inheritance:\n\n")

if __name__ == '__main__':
    generate_op_docs()
```

## 5. 构建和部署

### 5.1 本地构建

```bash
# 生成算子文档
python scripts/generate_op_docs.py

# 构建HTML
cd docs
make html

# 查看文档
open build/html/index.html
```

### 5.2 自动构建脚本

```bash
#!/bin/bash
# scripts/build_docs.sh

set -e

echo "生成算子文档..."
python scripts/generate_op_docs.py

echo "构建Sphinx文档..."
cd docs
make clean
make html

echo "✓ 文档已生成: docs/build/html/index.html"
```

### 5.3 GitHub Actions自动部署

```yaml
# .github/workflows/docs.yml
name: Build and Deploy Docs

on:
  push:
    branches: [main]
  pull_request:
    branches: [main]

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      
      - name: Set up Python
        uses: actions/setup-python@v4
        with:
          python-version: '3.8'
      
      - name: Install dependencies
        run: |
          pip install -e .
          pip install sphinx sphinx-rtd-theme sphinx-autodoc-typehints
      
      - name: Build docs
        run: |
          bash scripts/build_docs.sh
      
      - name: Deploy to GitHub Pages
        if: github.ref == 'refs/heads/main'
        uses: peaceiris/actions-gh-pages@v3
        with:
          github_token: ${{ secrets.GITHUB_TOKEN }}
          publish_dir: ./docs/build/html
```
