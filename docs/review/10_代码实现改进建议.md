### 3.5 增强 OpSpec 注册时校验

**当前问题**: `testpipe/core/registry.py` 注册时校验较弱

**建议增强**:

```python
def register_op(cls):
    """Register a TestOp class with validation."""
    if not hasattr(cls, "spec"):
        raise RegistryError(f"{cls.__name__} missing spec attribute")
    
    spec = cls.spec
    
    # 校验 op_type 唯一性
    if spec.op_type in _OP_REGISTRY:
        raise RegistryError(f"duplicate op_type: {spec.op_type}")
    
    # 校验输入输出端口名称不冲突
    input_names = {p.name for p in spec.inputs}
    output_names = {p.name for p in spec.outputs}
    if input_names & output_names:
        raise RegistryError(f"{spec.op_type} has overlapping input/output names")
    
    # 校验属性名称唯一
    attr_names = [a.name for a in spec.attrs]
    if len(attr_names) != len(set(attr_names)):
        raise RegistryError(f"{spec.op_type} has duplicate attr names")
    
    _OP_REGISTRY[spec.op_type] = cls
    return cls
```

**优先级**: P1 - 提升健壮性

**预计工作量**: 0.5 天

### 3.6 实现 ResourceResolver

**当前状态**: 未实现资源获取能力

**影响范围**: 无法支持从 Git/URL/本地路径获取测试资源

**建议实现**:

```python
# testpipe/infra/resource.py (新建)
class ResourceResolver:
    """Resolve and fetch resources from various sources."""
    
    def __init__(self, action_runner):
        self.action_runner = action_runner
    
    def fetch(self, resource_uri, target_dir, *, step_name):
        """Fetch resource and return local path.
        
        Supports:
        - file:///path/to/file
        - git://repo.git#branch:path
        - https://url/to/file
        """
        if resource_uri.startswith("file://"):
            return self._fetch_local(resource_uri, target_dir)
        elif resource_uri.startswith("git://"):
            return self._fetch_git(resource_uri, target_dir, step_name)
        elif resource_uri.startswith("http"):
            return self._fetch_http(resource_uri, target_dir, step_name)
        else:
            raise ValueError(f"unsupported resource URI: {resource_uri}")
```

**优先级**: P1 - 增强易用性

**预计工作量**: 2 天

## 9. 风险与注意事项

### 9.1 SSH 连接管理

**风险**: SSH 连接泄漏或超时

**建议**: 
- 使用连接池管理
- 在 `ExecutionContext` 中统一管理连接生命周期
- 确保 `finally` 块中释放连接

---

### 9.2 文件传输性能

**风险**: 大文件传输阻塞执行

**建议**:
- 实现传输进度回调
- 支持断点续传
- 根据文件大小自动选择传输策略

---

### 9.3 远程命令超时

**风险**: 板端推理耗时长，默认超时不够

**建议**:
- 在 `CaseSpec` 中支持 `timeout` 配置
- 在 `OpSpec` 的 `AttrSpec` 中支持 `timeout` 属性
- 提供合理的默认值（如 600 秒）

---

### 9.4 错误信息可读性

**风险**: 失败时错误信息不够明确

**建议**:
- 在 `summary.json` 中记录详细错误上下文
- 在 `reproduce.sh` 中添加注释说明
- 在控制台输出中高亮关键错误信息
