# TestPipe平台使用指南

---

## 1. 快速开始

### 1.1 安装

```bash
# 克隆仓库
git clone https://github.com/your-org/testpipe.git
cd testpipe

# 安装依赖
pip install -e .

# 验证安装
testpipe --version
```

### 1.2 5分钟上手

**步骤1: 准备Pipeline**

创建 `my_pipeline.json`:
```json
{
  "Pipeline_Name": "Simple_Test_Pipeline",
  "Pipeline_Inputs": ["input_data"],
  "Pipeline_Outputs": ["result"],
  "Nodes": [
    {
      "Node_Name": "process",
      "Op_Type": "Echo",
      "Inputs": [{"Name": "input_data"}],
      "Outputs": [{"Name": "result"}],
      "Attributes": []
    }
  ]
}
```

**步骤2: 准备TestCase**

创建 `my_testcase.yaml`:
```yaml
test_case:
  name: My_First_Test
  pipeline: Simple_Test_Pipeline
  inputs:
    input_data: "Hello TestPipe!"
  expected:
    result: "Hello TestPipe!"
```

**步骤3: 运行测试**

```bash
testpipe run my_testcase.yaml
```

## 2. Pipeline编写指南

### 2.1 Pipeline结构

Pipeline使用JSON格式,描述测试流程:

```json
{
  "Pipeline_Name": "名称",
  "Pipeline_Description": "描述",
  "Pipeline_Inputs": ["输入参数列表"],
  "Pipeline_Outputs": ["输出结果列表"],
  "Nodes": [
    {
      "Node_Name": "节点名称",
      "Op_Type": "算子类型",
      "Inputs": [{"Name": "输入名"}],
      "Outputs": [{"Name": "输出名"}],
      "Attributes": [
        {"Name": "属性名", "Type": "类型", "Value": 值}
      ]
    }
  ]
}
```

### 2.2 算子级联

算子通过输入输出名称自动连接:

```json
{
  "Nodes": [
    {
      "Node_Name": "step1",
      "Outputs": [{"Name": "data"}]
    },
    {
      "Node_Name": "step2",
      "Inputs": [{"Name": "data"}],  // 自动连接到step1
      "Outputs": [{"Name": "result"}]
    }
  ]
}
```

### 2.3 完整示例

参考 `examples/pipelines/atc_e2e_pipeline.json`

## 3. TestCase编写指南

### 3.1 基础TestCase

```yaml
test_case:
  name: 测试用例名称
  description: 测试用例描述
  pipeline: Pipeline名称
  
  inputs:
    param1: value1
    param2: value2
  
  expected:
    output1: expected_value1
    output2: ">= 0.99"  # 支持条件表达式
  
  tags: [tag1, tag2]
  priority: P0
  timeout: 3600
```

### 3.2 多Pipeline测试

```yaml
test_case:
  name: Multi_Pipeline_Test
  pipelines:
    - name: Pipeline1
    - name: Pipeline2
  
  inputs:
    shared_input: value  # 所有Pipeline共享
```

### 3.3 参数化测试

```yaml
test_case:
  name: Parameterized_Test
  pipeline: My_Pipeline
  
  parameters:
    soc_version: ["Ascend310P3", "Ascend910B"]
    precision: ["FP16", "FP32"]
  
  inputs:
    model: "model.onnx"
```

自动生成4个测试实例。

## 4. CLI命令参考

### 4.1 运行测试

```bash
# 运行单个TestCase
testpipe run testcase.yaml

# 运行多个TestCase
testpipe run testcases/*.yaml

# 运行TestSuite
testpipe run testsuite.yaml

# 指定输出目录
testpipe run testcase.yaml --output results/
```

### 4.2 可视化Pipeline

```bash
# 导出ONNX
testpipe export pipeline.json --format onnx --output pipeline.onnx

# 导出DOT图
testpipe export pipeline.json --format dot --output pipeline.dot

# 导出并渲染
testpipe export pipeline.json --format dot --render
```

### 4.3 查看算子

```bash
# 列出所有算子
testpipe list-ops

# 查看算子详情
testpipe describe-op ATCCompile
```

### 4.4 查看结果

```bash
# 查看测试结果
testpipe results

# 查看特定TestCase结果
testpipe results My_Test_Case
```

## 5. 内置测试算子

### 5.1 环境检查算子

**EnvCheck** - 检查测试环境

```json
{
  "Op_Type": "EnvCheck",
  "Attributes": [
    {"Name": "check_items", "Type": "strings", "Value": ["python_version", "atc_tool"]}
  ]
}
```

### 5.2 模型准备算子

**ModelPrep** - 准备模型文件

```json
{
  "Op_Type": "ModelPrep",
  "Inputs": [{"Name": "model_source"}],
  "Outputs": [{"Name": "model_path"}]
}
```

### 5.3 ATC编译算子

**ATCCompile** - ATC模型编译

```json
{
  "Op_Type": "ATCCompile",
  "Inputs": [
    {"Name": "model_path"},
    {"Name": "soc_version"}
  ],
  "Outputs": [{"Name": "om_path"}],
  "Attributes": [
    {"Name": "framework", "Type": "int64", "Value": 5},
    {"Name": "output_type", "Type": "string", "Value": "FP16"}
  ]
}
```

### 5.4 文件传输算子

**Transfer** - 文件传输

```json
{
  "Op_Type": "Transfer",
  "Inputs": [{"Name": "local_path"}],
  "Outputs": [{"Name": "remote_path"}]
}
```

### 5.5 推理算子

**Inference** - 模型推理

```json
{
  "Op_Type": "Inference",
  "Inputs": [
    {"Name": "om_path"},
    {"Name": "input_data"}
  ],
  "Outputs": [{"Name": "output_data"}]
}
```

### 5.6 精度检查算子

**AccuracyCheck** - 精度比对

```json
{
  "Op_Type": "AccuracyCheck",
  "Inputs": [
    {"Name": "output_data"},
    {"Name": "golden_output"}
  ],
  "Outputs": [
    {"Name": "test_passed"},
    {"Name": "accuracy_score"}
  ],
  "Attributes": [
    {"Name": "threshold", "Type": "float", "Value": 0.99}
  ]
}
```

完整算子列表请查看在线文档。

## 7. 常见问题

### Q1: 如何调试Pipeline?

```bash
# 使用verbose模式
testpipe run testcase.yaml --verbose

# 查看日志
testpipe run testcase.yaml --log-level debug
```

### Q2: 如何复用Pipeline?

多个TestCase可以引用同一个Pipeline:

```yaml
# testcase1.yaml
test_case:
  pipeline: Common_Pipeline
  inputs: {param: value1}

# testcase2.yaml
test_case:
  pipeline: Common_Pipeline
  inputs: {param: value2}
```

### Q3: 如何处理大量测试数据?

使用参数化测试:

```yaml
parameters:
  model: ["model1.onnx", "model2.onnx", "model3.onnx"]
  soc: ["310P3", "910B"]
```
